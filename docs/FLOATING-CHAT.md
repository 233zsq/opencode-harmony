# 悬浮对话界面

本轮保留会话标题，将它与右侧 Agent 按钮做成独立的毛玻璃胶囊。标题保持单行省略，长名称可收缩，避免挤出 Agent。正文列表覆盖整个聊天区域，标题、输入栏及“回到最新”叠放在列表上方；不再分配一条实色工具栏。

输入栏保留原有底部间距，任务状态以 9fp 小字放在下沿，不占新的布局行。正在读取附件、生成、停止、发送待核对、待处理和连接状态按优先级显示；发送结果待核对时仍可点击同步，待处理入口仍能打开审批与问题。附件缩略图和多行草稿可扩展，停止/发送与加号均为 40vp，保持底部对齐。

列表根据实际测得的顶部浮层和输入区域高度设置 `contentStartOffset` / `contentEndOffset`。滚动过程中内容可以经过玻璃后方，滚到两端时首尾消息仍能露出。底部间距随附件和多行输入更新，不使用覆盖整段正文的实色背景。

侧栏新增唯一的“工作空间”按钮，点击向上打开二级浮层，内含项目与会话、待办中心、代码审查、模型与接入、任务提醒。连接信息继续留在侧栏底部。浮层的第一次返回或外部点击只关闭浮层；选择目的地后关闭侧栏并进入对应原生页面。历史仍占侧栏至少三分之二，保留搜索与归档能力。

模型与工作空间使用同一套 `bindPopup` 材质与关闭逻辑；附件、历史筛选菜单通过 `MenuOptions.systemMaterial` 使用同样的 API26 THIN 沉浸光感。API24 不加载 API26 模块，沿用模糊与半透明色。任意自定义容器上的原生 `systemMaterial` 有适用位置限制，因此悬浮输入栏和标题使用可移植的 `backgroundEffect`，不把无效属性当作已接入系统光感。

## 模拟器复现

先明确连接仅监听 loopback 的本机 fixture，打开 `ses_fixture` 并确认“本机测试模型”，同一设备顺序运行：

```powershell
$env:OPENCODE_FIXTURE_PORT='55269'
node tests/floating-chat-ui.mjs
node tests/model-popup-ui.mjs
node tests/history-sidebar-ui.mjs
node tests/chat-layout.mjs
```

`floating-chat-ui.mjs` 检查正文与浮层的重叠区域、标题/Agent 不重叠、状态位置、输入栏底部锚点、加号与发送/停止中心、生成状态切换、回到最新、附件菜单、软键盘草稿、工作空间尺寸/返回/外部点击/导航和深浅主题。脚本不发送模型提示，结束时恢复原主题并清空测试草稿。

API24 真机、平板横屏与分屏、大字体及真实设备材质帧率留待后续验收。模拟器几何与逻辑检查不能替代这些设备结论。

## 本轮验收结果

- 273 项 Node、2 项 Python 回归通过；最终 ArkTS 构建、原有调试签名和 API26 模拟器安装启动通过。
- 新增原生检查通过：悬浮标题与输入区、状态下沿与输入栏底部固定、按钮中心、生成/结束状态、最新结果不被遮住、回到最新、附件菜单、工作空间二级浮层的尺寸/外部关闭/返回/导航、深浅主题。
- 实际可见的输入法皮肤边界下，输入栏位于键盘上方；草稿输入后清空。API26 的部分键盘 WindowScene 根节点覆盖整屏，不能把窗口根节点上沿当作键盘遮挡边界。
- 原生模型切换检查通过：当前项零提交、拒绝后重试、准确模型 ID、完整目录入口和返回。历史栏至少保留 66% 高度、十条可见历史，搜索/归档/外部点击与主题切换通过。
- 几何检查仍为：折叠思考到正文 8vp，工具到下一段思考 14vp，空输入 42vp，三行输入增加至 86vp，按钮保持底部对齐。独立旧多行脚本未取得键盘窗口而跳过该项；键盘遮挡结论来自上述新增脚本的可见输入法皮肤检查。

详细本机证据保存在被忽略的 `.test/floating-chat-*.log`、`.test/floating-*.jpeg`。联调不调用真实模型，也不修改云服务器。结束后恢复原服务器和原主题，移除本轮测试配置、映射与本机 fixture。
