# 连接、分叉与长会话管理（2026-10-19）

## 连接管理

服务器连接页提供编辑、取消编辑和原生移除确认。可修改名称、地址、用户名和密码；密码留空保留原凭据，主动勾选清除才删除。保存时冻结点击时的输入，期间禁用重复操作。

相同规范地址及账号不能重复添加：协议/主机大小写、默认端口和末尾斜线统一处理，路径仍区分大小写。无效地址、账号冒号/控制字符、超过长度限制及 HTTP/专用证书选项冲突均会提示。

修改名称或更新密码保留连接 ID、最近会话、书签和模型偏好。修改地址或账号会先清理该连接旧的本机会话位置、书签、模型偏好与暂存草稿，避免将旧服务器路径带到新端点。保存、凭据或清理失败时尝试恢复原配置；回滚失败会明确要求核对，不能误报成功。

移除只清理本机连接、凭据和关联位置，不删除服务器会话，也不停止服务器任务。取消确认不会移除。读取密码仅用于连接及必要的失败回滚，不回填到编辑框。

## 消息分叉与编辑重发

- 用户消息旁的“编辑”打开编辑并分叉；助手回复下方“分叉”从所选消息之前创建分支；更多功能中的“分叉当前会话”复制已有历史。
- 服务器的 before 参数是排除所选消息的边界。编辑后的问题和可选原附件放入新分支草稿，由用户确认发送；原会话已有草稿、历史及后续消息保留。
- 分叉沿用当前工作区文件状态，不提供文件回滚。新会话显示分叉边界，并可返回原会话；会话列表标识分支或普通子会话。
- 沿用附件时重新读取原消息，验证身份、数量、类型及 1 MB 总量；不能完整读取时可取消沿用并在新草稿重新选择。取消沿用不要求读取大附件消息体。
- 编辑最多 20000 字符，沿用最多 4 个附件。通过既有草稿预算预留位置，避免创建后才发现无法保留编辑内容。
- 创建期间阻止重复点击。明确拒绝可重试；网络或 5xx 等不确定结果不自动重试，要求检查会话列表，再经显式确认解除标记。
- 关闭创建面板后收到成功结果时保留已创建会话及草稿，不强制跳走。切换服务器、会话或修改端点时隔离迟到结果。

## 上下文与用量

入口：更多功能 → 上下文与用量。

面板显示当前模型上下文上限，服务端记录的输入、输出、推理、缓存读取和缓存写入 Token，以及 USD 费用。缺失或无效值显示“未提供”，有效 0 保留为 0，极小正费用显示小于最小精度。读取失败保留上次结果并提示重试。没有把会话用量误算为当前上下文占用百分比。

手动压缩会调用当前模型，可能产生费用，需原生确认。提交采用固定请求 ID 和 queue 模式；提交回执只表示已接受，通过匹配的压缩消息或 inbox 记录显示等待、执行中、完成、失败及待核对状态。

未知提交先读取精确记录，已存在时不重复 POST；仍未找到且用户确认重试时沿用同一请求 ID。已提交/执行中不重复请求。状态读取失败保留记录，不误报完成。

分叉和压缩前重新检查运行任务、问题、审批、inbox 和待确认回退。压缩接口可能提交已暂存回退，因此存在 revert 时客户端拒绝继续。客户端预检无法锁住其他客户端，最终状态以服务器为准。
