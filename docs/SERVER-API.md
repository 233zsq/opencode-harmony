# 服务端兼容说明

本仓库是 ArkTS / ArkUI 鸿蒙远程客户端。账号后台、管理网站、代理部署和运营数据独立维护；构建客户端不需要私人云端仓库，也不需要本仓库启动后台服务。

## 协议基线

当前按 OpenCode v2.0.29 协议适配。模型、Agent 和工作目录在用户指定的服务器运行，客户端不附带模型 Key。

| 接口 | 客户端用途 |
| --- | --- |
| GET /api/info | 读取 version，要求 2.x；其他版本仍须实际核对兼容性 |
| GET /api/project | 项目列表，现有协议可返回数组 |
| /api/session/... | 会话、消息、模型、分叉、压缩及相关操作 |
| /api/event | SSE 实时事件，代理应允许流式传输 |
| V2 form / permission 接口 | 问答与工具审批，保持服务器端权限决策 |

在“服务器连接”填写 HTTPS 基础地址，客户端自行拼接 /api/...。/api/global/health 返回 404 不能据此判断账号密码错误；版本探测使用 /api/info。

## 认证与传输

- 使用服务器管理员提供的用户名与密码，经 HTTPS Basic 认证；它们与模型 Key、SSH 凭据是不同用途的凭据。
- 若服务器另有网页登录，浏览器 Cookie 不代替客户端 Basic。认证网关可在服务器内部转换凭据，客户端不应获取内部服务密码。
- 保留系统证书及主机名校验；专用证书模式须匹配应用配置的可信证书和公钥指纹。不要为连接问题关闭 TLS 校验。
- 限流与失效会话也可能表现为 401；不能把所有 401 都解释成用户输错密码。

## 可选云端扩展

| 路径 | 能力 |
| --- | --- |
| GET /client-cache/capabilities | 精简历史能力探测，现有扩展返回 data.version=1 |
| /client-cache/session/... | 精简历史与按需附件，减少重复传输 |
| /client-settings/providers/... | 受限模型渠道配置，读取结果不返回模型 Key |

这些能力由服务端按需提供，相关客户端功能以服务端实际支持为准。它们不是客户端构建依赖，不需要复制账号网站、部署脚本或运营数据库。使用自有 OpenCode 服务时先核对协议与扩展支持。

## 测试范围

`npm test` 使用本地替身，不读取生产账号或调用模型。设备、真实服务和模型脚本仅由操作者显式运行，所需目标、凭据、CA/PIN 及模型开关见[构建与验证说明](BUILDING.md)。

拆仓仅移出当前版本的云端文件，不改变既有公开 Git 历史，也不改变客户端协议或已部署服务。
