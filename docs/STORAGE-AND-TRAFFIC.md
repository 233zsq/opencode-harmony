# 本机缓存与服务器流量

完整历史和 Agent 工作目录仍由服务器保存。本机只缓存最近打开的会话尾页（每个会话最多 30 条）与附件，用于更快打开和断网只读；本机缓存不替代服务器备份。

## 使用

在“更多功能 → 存储与流量”查看占用或清理。默认逻辑容量为 200 MiB，按最近使用淘汰；数据库页、索引和加密有额外开销。清理确认后同时回收数据库空闲页，不删除服务器历史、文件或模型配置。

原生 relationalStore 使用 S3、encrypt=true，密钥由系统管理。初始化失败时提示并继续联网使用，不降级成明文文件。按规范化服务器地址和用户名做 SHA-256 命名空间，再按工作目录和会话隔离；移除连接或变更地址/账号会清理对应旧缓存。附件按内容 SHA-256 去重，清理时的未完成网络响应不能把旧结果写回。

缓存只含聊天正文、已返回的思考文本、工具记录和附件，不持久化待回答/审批卡片、API 密码或待发送草稿。审批仍须实时核对。断网缓存显示明确状态，不能离线发送。认证/证书失败不会用离线恢复掩盖错误。

## 下载策略

- 正文和思考由现有 SSE 更新；工具等离散事件合并约 750 ms 后核对。
- 前台空闲且 SSE 正常：每分钟核对轻量会话版本，变化后同步；完整尾页兜底间隔 5 分钟。
- 运行中：轻量核对间隔 15 秒，完整尾页兜底 30 秒。SSE 不可用时空闲完整核对 15 秒。
- 待发送结果核对、用户手动同步、回前台和服务器事件仍可提前触发同步。后台暂停周期性历史轮询。
- 启用能力协商的服务器：尾页只返回附件名称、类型、大小和摘要，点击附件才读取内容；本机已有相同摘要时复用，避免历史轮询反复携带 Base64。
- 普通 OpenCode V2 服务没有这组可选路由时，自动继续使用原协议；此时服务器历史仍可能内联附件，节省主要来自减少轮询和本机打开缓存。
- 手动导出完整会话仍按现有导出流程请求服务器，可能产生较多流量。

服务器新增的只读 /client-cache/ 路由采用与 /api/ 相同的所有者 Basic 认证。Nginx 核验后注入内部凭据，浏览器会话 Cookie 不能代替 API 认证；代理只访问固定的 loopback 上游、不跟随重定向和环境代理。附件请求需同时匹配会话、消息、索引及 SHA-256。

## 网页统计

登录自己的 OpenCode 域名首页后查看“本月 HTTP 出流量”。手机页面有对应入口；密码不进入 URL，也不缓存网页登录 Cookie。

最小 Nginx 日志只记录时间、固定项目名和响应字节数。OpenCode、FieldNotes 和其他已配置站点分别累计，内部 443 → 9443 转发排除，避免重复计算。原始计数日志轮转保留 14 份，单份以 10 MiB 为轮转触发阈值（受 logrotate 执行频率影响）；统计每 5 分钟更新，按北京时间自然月汇总。

这是**从启用时开始的、已完成公网 HTTP 响应**统计。持续 SSE 要在连接关闭后计入；不包含 TLS/TCP 开销、向模型提供商发出的请求、SSH、其他进程或未接入站点，不能还原启用前已用流量，也不能据此计算云套餐剩余额度。500 GB/月的账单及重置时间仍以腾讯云控制台为准。

聚合服务以独立无登录用户运行，只读取计数日志并写自己的状态目录；账号服务只获得读取汇总的组权限，不向网页返回原始日志。

## 验证

- tests/transcript-cache.test.mjs：真实 SQLite 上的串行读写、重启恢复、账号/工作目录隔离、附件去重、LRU、损坏回退与清理；Node 平台替身不证明设备加密。
- tests/state.test.mjs：同步调度、迟到响应、清理期间写入、离线只读恢复、普通服务回退及附件重复打开复用。
- tests/account_cache_test.py、account_proxy_test.py：受保护的轻量历史、附件摘要、输入边界、真实 Nginx auth_request 和私有统计认证。
- tests/traffic_summary_test.py、traffic_entry_test.py：月界、增量/轮转/未写完记录、幂等累计、内部转发排除及最小日志字段。
- API26 模拟器：加密 RDB 成功写入 0.3 MiB 本机测试数据；健康 SSE 空闲观察 16 秒未新增完整历史读取；增强协议打开历史未下载附件正文，首次预览仅下载一次；停止本机服务、结束进程再启动后恢复离线正文和已打开的附件；清理取消保留数据，确认清理并再次重启保持 0。
- 此轮未做 API24 真机验收；新流量统计不等同于腾讯云计费实测。

scripts/deploy-traffic-entry.py 是对已部署私有账号入口的一次性迁移工具，固定源配置摘要并保留 root 私有备份。适用于脚本指定的部署基线，其他服务器应先检查并适配，不能直接照搬执行；脚本不会读取或修改所有者口令。
