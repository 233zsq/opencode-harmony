# 模型偏好与思考档位（2026-10-22）

## 使用方法

对话顶部的模型按钮打开 272vp 的沉浸光感浮层。喜爱模型是快捷入口；“全部模型”和“思考程度”在同一浮层内展开，搜索只覆盖已启用的模型。历史模型常驻底部、位于“模型与接入”上方，最多两个，按最近成功选择排序，排除喜爱、停用及服务器不可用的模型。

“模型与接入”新增“喜爱模型”和“启用模型”。点击星标添加喜爱时同时启用；取消喜爱仍保留启用，关闭启用则同时移除喜爱。初次使用需要主动启用模型，也可直接添加喜爱。设置页支持完整目录搜索与每批 40 个；浮层内每批 30 个。服务器已选的会话模型仍显示在顶部，停用是本机列表偏好，不会修改服务器会话或其他客户端。

这些偏好按本机服务器连接 ID 保存。重启保留；切换服务器隔离；删除连接或更改连接身份时清除相应偏好。历史记录内部保留最近 30 个选择，以便排除喜爱后仍可补足两项；打开或恢复会话本身不改变选择历史。写盘失败保留之前的偏好并显示错误。

## 思考设置的协议

以 [OpenCode v2.0.29 的模型定义](https://github.com/anomalyco/opencode/blob/v2.0.29/packages/schema/src/model.ts) 和 [官方模型文档](https://opencode.ai/docs/models/) 为依据。客户端使用目录里的 `variants[].id`，通过 `POST /api/session/{sessionID}/model` 发送 `{ model: { id, providerID, variant } }`。默认档位省略 `variant`，清除旧覆盖。已知 ID 翻译为中文，同时显示原始 ID；自定义 ID 原样保留。没有档位的模型显示“模型默认”，禁用展开，不猜测各提供商参数。

收到成功回执后再读取会话模型，确认模型及档位一致才更新选中态。当前相同选择不重复提交；受控拒绝保留旧档位并允许重试；断网或回执不明时先核对会话，不自动重放写入。核对期间阻止发送及重复切换。

“全部模型”和“思考程度”的展开区只加 0.5vp 细描边，不增加底色或另一层模糊，直接共用外层模型浮层的沉浸光感材质。搜索使用普通中性输入框，文字为 12fp/Normal。

浮层字体统一使用系统字体：主项目 14fp/Medium，渠道、ID 和档位说明 11fp/Normal，当前档位 14fp/Normal，空态和错误 12fp/Normal；历史标题使用 11fp/Medium。

浮层锚点独立于 Navigation 自定义标题，防止后台同步重建标题时清空展开状态和搜索输入。API26 使用原生 `systemMaterial`，API24 保留受运行时能力保护的模糊材质回退。

## 验证与边界

- 289 项 Node 回归、2 项 Python 域校验通过，包括服务器隔离、写盘回滚、精确请求、未知档位拒绝、回执丢失和迟到响应。
- 本机调试签名构建、保留数据安装、API26 模拟器通过。
- 原生验收覆盖首次空列表、星标自动启用、设置页导航、最近两项及排除规则、停用后各列表同步移除、搜索、轮询后展开/搜索保留、外部/返回关闭、默认/进阶切换、拒绝/重试、进程重启后恢复以及浅深色浮层。
- 实际软键盘显示后，搜索文字、焦点和键盘在后台同步周期后仍保留，搜索栏位于键盘上方。验证先点击聚焦并等待输入法，再注入合成文本，避免硬件快捷键影响输入法显示。
- 本轮仅向 loopback 测试服务提交模型选择；未发送提示词、第三方凭据或修改云服务器。真实提供商是否支持某一档位取决于其服务器声明和实际调用，本轮未执行真实推理。API24、真机与横屏/分屏延后。

模型原生回归使用 `tests/model-controls-ui.mjs`，替代旧的独立完整模型页与三项快捷列表脚本。需先启动 `tests/fake-server.mjs`、配置 HDC 反向端口并创建新的专用本机测试连接，选择 Harmony Fixture / ses_fixture。该连接必须尚未设置模型偏好，顶部显示“本机测试模型”。脚本仅修改这份连接；结束后删除专用连接、恢复原有连接与外观，并移除自己创建的端口映射和测试进程。

```powershell
node tests/fake-server.mjs
# HDC reverse port and the owned local test connection must be prepared first.
node tests/model-controls-ui.mjs
```

使用非默认测试端口时，测试服务设置 `PORT`，原生脚本设置同值的 `OPENCODE_FIXTURE_PORT`；默认均为 4210。截图、布局和脱敏回执保留于忽略的 `.test`，签名及连接凭据不提交。
