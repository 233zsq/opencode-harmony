# 本轮完善记录

2026-10-15。沿用 ArkTS + ArkUI、兼容 API24、编译 API26。

## 真实搜索超时

专用实例没有系统 rg 或本实例缓存二进制。通过官方 `tool.list()` / `command.transform()` 临时诊断直接执行真实 glob（不调用模型），最小验收仓库稳定在 30007ms 报搜索超时。补齐官方 ripgrep 15.1.0 x64 musl 后，同一调用13ms返回 greeting.ts；内置 MiMo 真实工具调用另以48ms完成。只新增专用实例缓存依赖，无服务重启。

依赖归档来自 [ripgrep 官方15.1.0发布](https://github.com/BurntSushi/ripgrep/releases/tag/15.1.0)，SHA256为 `1c9297be4a084eea7ecaedf93eb03d058d6faae29bbc57ecdaf5063921491599`，与官方 GitHub release asset digest 一致。`scripts/install-search-dependency.sh` 校验摘要、所有权标记和路径，拒绝覆盖不同版本。后续重建实例应先提供依赖，避免首次任务等待自动下载。

`tests/glob-live.test.mjs` 只在显式指定的合成验收目录中创建测试会话，内置免费 MiMo 只自动获准 glob，其他工具需人工审批且测试不会批准；成功必须返回已知 greeting.ts。模型出错及时停止，不将外部模型失败冒充搜索失败。

初次 deny-all 测试返回 MiMo provider.auth403；相同官方 OpenCode 内置模型改为其他工具 ask 后成功，未伪造身份头、借用凭据或放宽全局策略。[官方同类问题](https://github.com/anomalyco/opencode/issues/50627) 表明禁用工具可能触发免费入口误判；这属于本次受控验证结果，不能保证其他配置永远可用。

## 会话修改

代码审查新增“会话修改”，按服务器 idle 标记合并运行中追加的消息；读取 `/api/session/{id}/diff?from=<prompt>&context=3` 的真实任务快照。当前 Git Diff 和文件浏览保留。更早记录按需分页，最多300条；起点不完整的任务先加载前页再查看，避免把追加消息误认成独立任务。

选中不同任务先清空旧 Diff，并用请求序号与连接代数隔离迟到响应。同路径不同 patch 更新渲染标识。空修改、读取失败、任务进行中分别提示；预览仍有明确1500行上限。

## 手机配置

配置页拆为提供商、兼容渠道、模型目录。OpenCode/MiMo、DeepSeek 快捷入口采用服务器声明的认证方式；模型搜索显示真实服务器目录并限制展示数量。自定义渠道明确新增/编辑，已有 ID 锁定，新建/切服清空旧表单与 Key，编辑 Key 留空保留且不回显。

提交前提示 Base URL、完整请求路径、重复模型、长度、普通文本与插值格式问题，服务端公网地址、写入范围、任务空闲和原子保存校验仍为最终边界。保存和目录列出均不代表实际调用成功；真实测试继续使用内置 MiMo，不自动调用付费模型。
