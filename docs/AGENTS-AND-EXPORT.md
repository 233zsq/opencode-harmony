# Agent 与会话导出（2026-10-19）

## 使用入口

打开会话后，标题旁显示当前 Agent。点击可查看服务器提供的名称、用途、默认模型及 ID，并按名称、ID 或说明搜索；只显示可选的 primary/all Agent，隐藏内部 Agent 和 subagent。列表超过 40 项时分批展示。

聊天页右上角“更多功能 → 导出当前会话”可选择 Markdown 或纯文本。默认导出用户与助手正文及公开切换状态；附件只列名称、类型和大小。思考记录、内部消息、手机 URI 和附件内联字节不导出。工具参数和输出需主动勾选。

## 切换行为

- 使用固定 OpenCode v2.0.29 的 GET /api/agent 和 POST /api/session/{id}/agent，提交实际 Agent ID，影响后续轮次；切换后重新读取会话，更新 Agent 与模型。
- 切换前重新检查运行任务、Question 与审批；发送结果待确认时也不切换。客户端检查无法锁住其他客户端的并发操作，最终行为仍由服务器决定。
- 提交期间禁止重复切换、发送和模型切换。明确拒绝后可手动重试；网络错误、5xx 或成功提交后读回失败时，显示“结果待确认”，要求重新读取，避免自动重复提交。
- 会话/项目/服务器切换隔离迟到响应；较旧的同步结果不能覆盖刚确认的选择。Agent 说明和名称来自服务器，不在客户端预设权限承诺。

## 导出边界

- 先读取末条消息 ID，再从最早页向后读取，直到该 ID；不局限于聊天界面最多保留的 300 条消息。启动后新增的消息不纳入本次导出。生成中的内容以各页读取时为准，不承诺事务快照。
- 保留不透明游标，后续页不混入 order；按消息 ID 去重。大附件页超过既有 2 MB 读取限制时，可回退到单条读取；单条仍超限则明确失败。
- 进度显示已读取的可导出消息数；关闭面板、取消、切换会话或断开连接会取消任务并丢弃迟到结果。正在进行的 GET 可能要等返回或超时后结束；取消不会继续请求后续页。
- 单次最多 10000 条可导出消息、8 MiB UTF-8 文本、2000 页。达到上限、分页循环、末条消息消失或读取失败时显示未完成，不把部分内容当作成功文件保存。
- 完整准备后才打开鸿蒙系统文件保存器。取消系统保存可重新导出；写入处理短写、零写、刷新失败并关闭文件。选择目标后若会话已变化，不打开/截断目标。写入已经开始后，会完成该文件写入或报告失败。
- 工具内容可能包含用户项目中的敏感文本；用户主动勾选后才加入导出。文件不会上传到额外服务。

## 验证

- 185 项本机回归通过，包括 23 项 Agent/导出测试、13 项原生附件/保存适配器故障注入；另有 4 项 Node 合成负载检查通过。
- ArkTS 编译、HAP 打包与本机调试签名通过；编译 SDK26、最低兼容 API24。
- API26 本机 fixture：名称/说明搜索、隐藏和 subagent 过滤、准确 Agent ID、切换后的模型、HTTP400 重试、提交已生效但返回503后的读取确认且不重复提交、运行中禁止切换。
- API26 本机 fixture：导出读取失败、取消在途分页；360 条 TXT 通过系统保存并重新导入，核对首尾及总数、附件元数据与默认隐私边界；Markdown 勾选工具详情后再次保存和重新导入核对，取消系统保存后可重试。

本轮不调用真实模型、不修改真实服务器 Agent 或模型配置。真实 API24/API26 手机/Pad 的新版验收按使用者安排留待之后。

## 复现

    node tests/agent-export.test.mjs
    node tests/attachments.test.mjs
    powershell -File scripts/build.ps1
    node tests/fake-server.mjs
    node tests/agent-export-ui.mjs

原生脚本需要先通过 HDC 反向映射 4210，在 App 中连接明确标识的本机 fixture 并打开测试会话；脚本拒绝非测试模型。只写入本机合成历史、Agent 和文件，不执行模型任务。保存文件位于模拟器 Download，导入后的测试附件草稿会删除。完成后移除临时连接与反向端口，恢复原 HTTPS 配置。截图、布局和详细日志保存在忽略的 .test 目录。
