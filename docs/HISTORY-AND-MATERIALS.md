# 历史侧栏与系统光感（2026-10-21）

接续 [比例调整](HARMONY-UI-REFINEMENT.md)，本轮按使用者的新反馈，让侧栏集中展示历史；字号与聊天布局沿用上一轮。

## 历史优先

- 删除顶部 OpenCode 图标、名称、副标题、关闭按钮、整行新建按钮、项目行和固定工作区入口。标题行保留“历史对话/本机归档”筛选与 40vp 新建图标，下面是一行搜索。
- 对话列表占主要空间，普通历史行保持最低 44vp 与 3vp 间隔。置顶、任务状态、归档和会话操作仍沿用原状态与真实 ID。
- 手机侧栏约占窗口 84%，上限 320vp；宽屏嵌入栏 280vp。右侧露出的区域接受点击并消费事件，收起侧栏，避免误触下方新建或更多操作；系统返回仍可收起。宽屏嵌入栏不增加覆盖层。
- 底部只留服务器名称、连接状态和连接管理入口。待办、项目、代码审查、模型接入和提醒在聊天右上角“更多功能”中进入。
- “历史对话”下拉菜单切换最近/本机归档或刷新；搜索输入先过滤当前列表，搜索按钮或键盘搜索键查询服务器历史。没有把历史改成另一份本地聊天库。

## 材质与兼容

查阅[官方组件适配指南](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/arkts-immersive-light-sense-component-adaptation)和 [Popup 示例9](https://developer.huawei.com/consumer/cn/doc/doccenter-references/api/ts-universal-attributes-popup)：Popup 需要通过 options.systemMaterial 单独开启，应用级开关不会为它自动开启。此前模型浮层的内部实色背景也会挡住材质，本轮改为透明内容层。

- API26 原生浮层取得焦点，以 onWillDismiss 同步关闭状态；显隐回调只确认关闭，重复的已显示回调不会重新打开已经收起的浮层。专门检查主题切换后的一次打开、一次返回与随后导航。
- API26 模型浮层使用真正的 `uiMaterial.ImmersiveMaterial`，选择 `THIN` 并配置光感反馈；紧凑半模态使用 `REGULAR`。系统控制折射、模糊、高光、阴影及设备档位适配。
- `ImmersiveMaterials.ets` 先检查运行时版本与能力，再动态加载 API26 模块。API24 不加载该模块；加载失败返回普通毛玻璃回退。options.systemMaterial 赋值也有版本保护。
- 侧栏、输入区、模型按钮与底部连接栏使用较透的资源色、局部背景模糊和细描边；提高透明感，不改变整个控件或文字的 opacity。
- 大尺寸附件预览与管理正文保持清楚的阅读底色。没有给全部滚动卡片叠加动态系统材质；侧栏是背景模糊，不把它误称为官方原生沉浸光感。
- 不修改最低 API24、compile/target API26、调试签名或设备全局主题。真实折射效果和 GPU 开销仍取决于设备能力及系统设置，API26 模拟器不代替真机性能验收。

## 自动化中的输入法边界

API26 模拟器的实际输入法窗口是 keyboardPanel / keyboard WindowScene，窗口不一定带 inputmethod 包名。旧脚本只看 SkinBgContent，漏掉了仍打开的键盘，随后把输入法消费的点击和 Back 误记成应用浮层失败。native-driver 现在识别实际窗口，输入完成后显式收起并确认键盘退出；需要保留键盘的场景可传 keepKeyboard。原生编辑/主题/浮层回归检查的前提是键盘已收起，并等待原生入场动画稳定。没有保留试验性的输入法接口改动，也没有清除草稿或应用数据。

HDC 中还观察到原生面板退出后首个注入点击偶发未触发根菜单，原因尚未确认。脚本只在确认仍处于无浮层的聊天根页时，对无副作用的“更多”入口重试一次并写 INFO 记录；独立编辑/主题回归仍保留首次点击与首次返回的断言。不能据此声称真机首次触控已验收。

## 验证

完整构建、原调试签名安装启动通过。273 项 Node 和 2 项 Python 本地回归通过，其中新增 4 项检查 API24 零模块加载、API26 材质参数、能力不可用和模块加载失败回退，另有 4 项覆盖输入法窗口识别；不把这些 Node 检查当成真机效果验收。

API26 原生验收通过：侧栏约 84% 宽度、至少 72% 的可用高度用于列表、同时至少 10 行历史；点外部收起且不误触下方操作；最近/归档、搜索过滤、会话操作面板与返回、移动后的审查入口均通过。模型浮层在深浅主题下均有实际尺寸与可见选项；独立模型检查覆盖点外部/返回关闭、当前项零重复 POST、受控失败重试、精确 ID 和完整搜索入口。编辑/收起键盘/切换主题后的首次打开、首次返回与导航也通过。原生面板关闭与侧栏收起时清理焦点和显隐状态。本轮只使用 loopback fixture，不发送真实模型提示，不修改现有远程服务。

复现时先选择本机 fixture 会话并核对“本机测试模型”标签，同一设备的脚本顺序运行：

```powershell

node tests/material-focus-ui.mjs
node tests/history-sidebar-ui.mjs
node tests/model-popup-ui.mjs
node tests/luminous-ui.mjs
```

测试后移除本轮专用连接与 HDC 映射，停止本轮 fixture，恢复原 HTTPS 连接。截图和诊断日志只保留本机 `.test/history-glass-*`。
