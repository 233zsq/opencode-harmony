## Standards

固定头审查共 4 项：

- **P1 / 硬规则：上下文百分比误导。** UsagePanel:26–29、54–65 用会话累计输入除以模型上限画占用率，与面板说明和“只改视觉属性”约定冲突。已删除比值与进度条，保留服务端分类用量及独立模型上限。
- **P2 / 硬规则：Agent 控件结构和触控回退。** Index:549–555 把原生 Button 变成 26vp Row，ID 放进内部文字。已恢复 Button 与 40vp 触控高度；模型按钮、侧栏关闭和会话操作同样扩大。连接复选框保留原生语义、增加 40vp 响应区，说明文字也可切换选项。会话行改为最小高度，让放大文字有增长空间。
- **P2 / 硬规则：静态连接持续循环动画。** Material:64–66 和 Index:284、361、856 在空闲连接状态仍启动无限脉冲，与静态不 pulse 的设计约定冲突。状态标记已改静态；任务运行/待处理仍有明确文字，输入区原生进度指示保留。
- **P2 / 判断建议：重要说明对比偏低。** ProviderSettings:156–162 等必要说明使用小号 muted。原浅/深色色板在部分阅读底色约 2.87 / 3.50。已提高辅助文字对比，独立测试检查正文、次级文字、提示、按钮和代码文字在对应不透明底色至少 4.5:1；透明材质仍需视觉验收，不能只用资源颜色计算宣布整体无障碍达标。[W3C 普通文字对比说明](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)

原生关键控件按至少 40vp 的点击范围修正，保留紧凑视觉，而非把小图标直接当成整个触控目标。[华为触控热区检查](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides-v5/ide_touch-target-size-V5)
