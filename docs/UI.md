# 对话优先的界面

当前页面层级、字号和视觉以 [2026-10-21 历史侧栏与系统光感](HISTORY-AND-MATERIALS.md)为准；下面按日期保留此前的设计与验收记录。

按使用者提供的Kimi截图参考页面位置和收起方式，保留OpenCode自身模型、项目与审批语义。使用ArkUI原生组件，没有新增业务依赖或品牌素材。

## 页面与入口

- 启动页是对话；顶部左侧为历史侧栏，中间为当前模型，右侧为新对话和更多菜单。
- 侧栏提供当前项目、当前项目历史搜索、新对话、代码审查、模型接入和服务器连接。
- 手机及较窄的Pad窗口采用抽屉，点击右侧遮罩或收起按钮关闭；窗口宽度达到840vp时显示可收起的并排侧栏。
- 连接、项目、提供商设置和代码审查有独立页面，左上角返回当前对话。完整目录、账号和配置表单不占用主页。
- 已明确连接的服务器记为最近服务器，下次启动恢复该服务器及保存的会话位置；不存在该记录时展示对话欢迎页，不猜选其他服务器。
- 新会话立即加入历史，服务端标题变化同步到侧栏；搜索范围明确为当前项目的最近50个会话。

## 消息交互

- 用户消息右侧灰色气泡；助手正文直接阅读，减少每条回复的外框和标签。
- 思考流式输出时展开为有界区域；reasoning ended后立刻收起，即使正文或工具仍在生成。历史默认收起。
- 每条消息独立控制思考展开；保留“思考已完成”入口。再次出现新的思考部分时可自动显示，不删除服务端历史。
- 工具默认只显示名称、参数摘要、执行状态。点击后打开原生详情面板，分别展示调用参数与结果，运行中的结果自动更新。
- 工具失败保持明显状态。详情截断明确提示；不会把工具名称或本机fixture当成真实执行成功。
- 输入区保留发送、待核对重试、停止任务、回到最新和待处理入口。Question与审批仍直接展示，不因工具折叠而隐藏；批准前核对及断线恢复逻辑保留。

## 复现

启动tests/fake-server.mjs，仅监听PC loopback。为测试设备映射4210，先运行tests/approval-smoke.mjs connect，再依次运行：

    node tests/ui-smoke.mjs home
    node tests/ui-smoke.mjs sidebar
    node tests/ui-smoke.mjs thinking
    node tests/ui-smoke.mjs details
    node tests/ui-smoke.mjs menu

可通过HDC_TARGET指定设备，OPENCODE_UI_TAG为不同设备的截图和布局加前缀。最后按APPROVALS.md运行审批验收，并移除本轮fixture端口映射。

## 聊天细节修复（2026-10-18）

实际 API26 模拟器复现了工具调用到下一段思考之间约 93.4vp 的间距。根因是工具消息后的整行复制按钮、消息内间距、底部 padding 和列表统一间距相加；单独移除工具消息重复的复制行后变为 38.6vp，进一步统一间距后为 14.9vp。折叠思考到正文为 8vp。检查直接读取真实 ArkUI 节点 bounds，固定同一段服务器历史作前后比较，没有发送新任务。

- 思考折叠行 36vp，工具为 40vp 单行摘要，保留点击查看完整参数/结果。常用工具显示中文名称，路径摘要展示最后两段，完整路径仍在详情内。
- 工具消息不再额外占一整行复制按钮；普通回复保留紧凑复制按钮，正文可长按复制完整回复。
- 输入区移除无操作时的工具行及常驻说明，空态 42vp，三行输入实际展开为 86vp，最多显示五行。发送/停止控制位于输入区右侧，多行时与底部对齐，临时输入测试没有提交消息。
- 聊天改用干净的 surface 背景，标题栏历史按钮图标缩至 24vp，选择器及辅助控件尺寸统一。
- 加粗文件名中的行内代码不再露出反引号，代码长行横向滚动，滚动条与末行保留间隔，标题字重及正文行高修正。

原生几何回归（滚动到相邻工具/思考与正文同时可见的位置）：

    node tests/chat-layout.mjs
    node tests/composer-smoke.mjs

默认目标 API26 模拟器，默认密度 3.5；其他设备可通过 HDC_TARGET / UI_DENSITY 指定。REQUIRE_CHAT_CARDS=1 时要求两类卡片测量都存在，避免仅测到输入栏就当作卡片回归通过。输入检查会跳过已有用户草稿，只在空输入栏写入并清理已知三行样本；不点击发送。

本轮 API26 原生复验通过：思考手动展开/收起、工具详情参数与结果、侧栏历史与系统返回、标题控件不重叠、浅色/深色/跟随系统、深色重启恢复及深色审查分段。三行输入的发送按钮保持底部对齐，样本已清空。连续导航测试等待原生目的页退出后再点下一项，滚动查找使用目标所属容器，避免代码块新增横向滚动影响详情验证。模拟器自动化没有显示软键盘窗口，键盘几何避让明确跳过；本轮没有真机复验、服务器变更或外部模型调用。

## 视觉重构：Graphite + Liquid Glass（2026-10-20）

- **主题**：由浅灰/纯黑平铺改为 Graphite 石墨工具感。强调色收敛为单色钴蓝，只用于选中态、连接状态、链接和警告；主操作使用黑白实心按钮；取消多色渐变、发光和营销式欢迎页。
- **令牌**：base/dark 颜色资源更新为 Graphite 色板，并新增 `ui_btn/ui_btn_text`、`ui_glass_*`、`ui_sheet_scrim`、`ui_success`、`ui_chip`。全部经 `HarmonyColors` 访问，组件不再硬编码颜色。
- **材质**：新增 `components/Material.ets`（`GlassPanel`、`StatusLed`）。输入区、侧栏抽屉、浮动控件使用 `backgroundEffect` 模糊+饱和、半透明填充、1px 高光描边、内侧阴影与低阴影；半模态沿用系统 `bindSheet` 的 `blurStyle`、`maskColor`、`borderWidth/Color` 和 `shadow` 配置。消息正文、工具行、代码块保持实底，避免长文阅读干扰。
- **一级界面**：空态改为“继续工作”工作台（最近会话、工作区入口、SERVER/MODEL 状态）；顶栏模型选择器、会话状态行、侧栏品牌区、历史会话行、工作区导航、连接卡和悬浮输入区统一为发丝线 + 等宽元信息风格。
- **二级界面**：工具详情 Sheet（参数/结果 + 复制）、审批与提问内联卡、模型与接入管理页、上下文与用量 Sheet 等统一卡片、主次按钮、状态灯、代码块与能力标签语言。消息操作行前移到工具行之前，避免工具与下一段思考之间重新出现整行操作行间距。
- **兼容**：材质全部基于 API24 可用的通用属性（`backgroundEffect`、`border`、`shadow`、`bindSheet.blurStyle`），未静态 import API26 专有模块；API26 系统组件沿用 `module.json5` 已启用的 UIMaterial 沉浸材质，低版本回退普通原生样式。
- **验证**：完整 ArkTS 构建、打包与签名通过；离线回归 212 项 Node + 4 项负载 + Python 通过。模拟器原生几何：折叠思考→正文 8.0vp（≤10）、工具→下一段思考 14.0vp（≤24）、空输入 42vp（≤48），三行输入 42→86vp 且发送按钮底部对齐。设备 UI 用例通过：首页、侧栏、管理导航、思考展开/折叠、工具详情、Question/Form、Provider 表单、Agent、会话导出、模型选择、SSE 重连与文件/Diff、外观、审批预览/失败/恢复/批准。软键盘几何在模拟器上仍 SKIP；API24 Pad 与真机需后续复验。12 屏视觉证据保存在本机 `ui-preview/impl/`（不提交仓库）。

## 移动端输入与提醒（2026-10-20）

- 软键盘/中文输入：应用用 `KeyboardAvoidMode.RESIZE`；实测真实输入法下中文三行输入、候选栏、键盘收起后输入区恢复均正常；输入区与发送按钮始终在键盘上方。打开模型/工具/会话/更多功能/侧栏前会收起键盘并保留草稿；切换会话与通知点击定位也会保留草稿。
- 自动跟随：用户上滑或触摸历史时停止跟随并出现“回到最新”，滚到底部自动恢复；键盘弹出造成高度变化时只有仍处于跟随状态才滚到最新。
- 大字号：`AppScope` 配置跟随系统字体，`fontSizeMaxScale` 上限 1.75；思考/工具/列表/面板/审批/提醒设置改为 `minHeight` 或自适应高度。模拟器“超大”字体下标题、侧栏、审批卡与提醒页无重叠，超过 1.75 的倍率被截断。
- 无障碍：图标按钮补无障碍名称，思考/审批/模型/Agent/提供商等补展开或选中描述；小控件通过 `responseRegion` 扩到 ≥40vp 热区，视觉尺寸不变。
- 验证与边界：软键盘/中文候选栏/大字号在 API26 模拟器实测；橫屏、分屏、Pad、API24 与真机输入法仍需设备验收。详见 [MOBILE-USABILITY.md](MOBILE-USABILITY.md)，提醒能力边界见 [NOTIFICATIONS.md](NOTIFICATIONS.md)。
